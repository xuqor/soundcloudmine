# SoundCloud Mine — Fabric 1.21.11

Минималистичный клиентский музыкальный плеер прямо в Minecraft: скруглённый тёмный GUI,
плавные анимации, поиск SoundCloud, очередь, повтор и перемешивание.
GUI рисуется **своим OpenGL-рендерером через LWJGL**; стандартные кнопки и шрифт Minecraft не используются.

## Установка готового мода

1. Minecraft **Java Edition 1.21.11**, Java **21 или новее**.
2. Установить Fabric Loader **0.19.5 или новее** и **Fabric API для 1.21.11**
   (сборка проверена с `0.141.6+1.21.11`).
3. Скопировать `dist/soundcloudmine-1.0.0.jar` в `.minecraft/mods/`.
4. Запустить игру. **M** открывает плеер. Клавишу можно поменять в настройках управления.
5. Ввести название трека или вставить ссылку через **Ctrl+V**, нажать Enter / «Найти».
6. В поиске нажать **+** для добавления в очередь. Ссылка на трек/плейлист сразу добавляет доступные треки.

Это **клиентский мод**, на сервер устанавливать его не нужно. У каждого слушателя свой плеер.
Синхронное прослушивание с другими игроками не реализовано.

## Управление

- ▶ / пауза — воспроизведение.
- `<<` — предыдущий трек; если прошло >3 секунд, сначала начинает текущий заново.
- `>>` — следующий. При окончании очереди и выключенном повторе плеер останавливается.
- **Loop → All → One** — повтор выключен / вся очередь / один трек.
- **Mix** — перемешивание, не выбирает только что сыгранный трек при очереди >1.
- Полоска VOL — громкость плеера независимо от громкости Minecraft.
- Нажать трек в очереди — воспроизвести его; `x` справа — удалить.
- Колёсико — прокрутить список.
- Esc / X — закрыть интерфейс; музыка продолжает играть.
- Пробел переключает паузу, когда поле поиска не в фокусе.
- Нажатие/отпускание на полоске прогресса — перемотка.

**Перемотка пока простая:** заново открывает поток и декодирует до нужного места без
сохранения файла. На длинных треках это может потребовать время и дополнительный трафик.
Мгновенная HTTP Range/HLS seek пока не реализована.

## SoundCloud без входа слушателя

В этой версии используется **неофициальный публичный веб-API SoundCloud**, как у веб-плеера.
Вход в аккаунт слушателя не требуется. `client_id` приложения автоматически определяется
из публичных скриптов SoundCloud и хранится только в памяти.

Это не официальная интеграция: сервис может изменить API, ограничить запросы или убрать
выбранные форматы. Работоспособность в будущем, во всех регионах и для всех треков не гарантируется.
Приватные, платные, заблокированные и preview-only треки не обходятся.
Пользоваться необходимо с соблюдением условий сервиса и прав на контент.

Если автоопределение перестало работать:
- открыть «Настройки» в плеере;
- вставить свой допустимый `client_id` через Ctrl+V;
- нажать «Готово».
- Backspace в настройках очищает ручной ID.

Не вставлять пароль, OAuth-токен, cookie или client secret. Мод их не использует.

Настройки: `.minecraft/config/soundcloudmine.json`:

```json
{
  "volume": 0.65,
  "clientId": "",
  "animations": true
}
```

## Поддерживаемые аудиопотоки

- SoundCloud **MP3 progressive** — предпочтительный вариант.
- SoundCloud **нешифрованный конечный HLS с MP3-сегментами** — резервный вариант.
- Прямые HTTP/HTTPS ссылки на MP3, если это поток аудио, а не HTML-страница.

AAC, Opus, DRM/шифрованный HLS, live HLS и byte-range HLS не поддерживаются.
Если сервер предлагает только эти форматы, плеер покажет ошибку.
Для вывода используется Java Sound / стандартное системное аудиоустройство,
а не движок звуков Minecraft. Конкретное звуковое устройство в GUI пока не выбирается.

## Память и диск

**Музыка не записывается на диск.** Только небольшой сетевой/PCM-буфер и текущий декодер.
После трека поток и аудиолиния закрываются; следующий трек использует новые/переиспользуемые буферы.
Список очереди сохраняет метаданные, а не музыку.

- Сетевой буфер: 64 KiB.
- PCM аудиолиния: примерно 250 мс, ~43 KiB при 44.1 kHz / stereo / 16 bit.
- Рабочий MP3 PCM-буфер: ~9 KiB.
- Атлас шрифта: 2048×1024 RGBA (~8 MiB в GPU; подготовка атласа временно требует CPU-памяти).
- Обложка: только текущая, с ограничением размера ответа 2 MB и измерений 1024×1024.
- Очередь и импорт плейлистов не ограничены искусственным числом элементов; дубликаты
  одного и того же трека автоматически объединяются.
- HLS держит список адресов сегментов, но открывает по одному сегменту, не весь трек.
- Java/HTTP/декодер/GUI добавляют накладные расходы. Полный дополнительный расход ОЗУ
  на Windows **не измерен**; прежний ориентир 20–60 MB не является гарантией.
- JVM может не сразу возвращать освобождённую память системе.
- На диск записывается только небольшой JSON настроек. Логи игры ведутся самим Minecraft.
- Очередь между перезапусками не сохраняется.

## Сборка проекта (разработчикам)

Для **сборки нужен JDK 25** из-за Fabric Loom 1.18.2 в предоставленном шаблоне.
Сам мод компилируется с `--release 21`. Это отличие между JDK сборки и Java запуска игры.

Windows:
```bat
gradlew.bat build
```

Linux/macOS:
```sh
chmod +x gradlew
./gradlew build
```

Готовый мод: `build/libs/soundcloudmine-1.0.0.jar`.
Файл `*-sources.jar` устанавливать в игру не нужно.
Первый запуск Gradle скачивает зависимости; сам мод не скачивает музыку в файлы.
Пользователю Windows не нужно запускать команды или устанавливать JDK: готовый файл
`dist/soundcloudmine-1.0.0.jar` копируется в `.minecraft/mods/`, после чего мод запускается
обычной кнопкой Play в установленном Minecraft Launcher.
UI smoke-режим: `./gradlew runClient -PpreviewUi` — открывает плеер из главного меню.

## Проверки

Подробности в [TESTING.md](TESTING.md).
Проверены сборка, unit-тесты очереди, реальный запуск GUI в Minecraft 1.21.11,
поиск/resolve SoundCloud и потоковое декодирование MP3 (progressive и HLS).
Пауза, автопереход, repeat-one и закрытие ресурсов проверены с тестовым MP3
на виртуальном аудиовыходе. Физический вывод звука и конкретные Windows/GPU-драйверы
в этой среде не проверены. Совместимость с Sodium/Iris/шейдер-паками отдельно не проверялась.

## Структура

- `api/` — SoundCloud, метаданные, MP3/HLS.
- `audio/` — декодер, очередь, жизненный цикл.
- `ui/` — самостоятельный OpenGL-рендерер и Screen для ввода.
- `mixin/OverlayMixin` — рисование после вывода кадра Minecraft перед swap buffers.
- `tools/` — ручные network/audio smoke-тесты.
- `dist/` — уже собранный устанавливаемый JAR.
- `preview.png` — реальный снимок GUI, не макет.
